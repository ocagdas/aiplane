# Getting help

Start with [README.md](README.md), [docs/index.md](docs/index.md) and [STATUS.md](STATUS.md).

Use repository issues for reproducible bugs and feature proposals. Select the
bug report or feature request form. Include the project version or commit, Python
version, OS, installation mode and a minimal disposable example. Redact credentials,
private code, media, personal data and local paths from logs.

For vulnerabilities, follow [SECURITY.md](SECURITY.md). For conduct concerns, follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Support is best effort; current execution
evidence and limitations are recorded in [VALIDATION.md](VALIDATION.md).
